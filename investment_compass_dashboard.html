9지표 채점 기준 (자체 설계 · 참고용)

종목별 6지표 (종목마다 다름)
· 52주 고점대비 하락률: 0~-5%(0점) / -5~-15%(+1) / -15% 이하(+2) — 많이 빠질수록 저가매력으로 가점
· 200일선 이격: -5% 이하(+1, 이평선 하회) / -5~+15%(0) / +15% 이상(-1, 과열)
· RSI(14): 30 미만(+1, 과매도) / 30~70(0) / 70 초과(-1, 과매수)
· FWD PER 3년 평균(트레일링 기준) 대비 괴리: -10% 이하(+2) / -10~+5%(0) / +5~+20%(-1) / +20% 이상(-2)
· 부채비율(총부채/자기자본): 0.15 이하(+1) / 0.15~1.0(0) / 1.0 이상(-1)
· EPS 성장률(전년비): 20% 이상(+2) / 5~20%(+1) / 0~5%(0) / 역성장(-1)
